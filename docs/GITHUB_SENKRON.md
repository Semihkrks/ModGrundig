# GitHub senkronu

Repo: https://github.com/Semihkrks/ModGrundig

Kök `README.md` herkese açık giriş sayfasıdır. GitHub About açıklaması ve konuları aynı kapsamı söyler: araştırma notları ve REA alt deposu. Lisans MIT’tir.

Araştırma belgeleri, scriptler ve analiz çıktıları main dalında tutulur. Büyük çağrı indeksi Git LFS kullanır; REA sabit commitli alt depodur (`git clone --recurse-submodules` ve `git lfs pull`).

Ham firmware, orijinal arşivler, çıkarılmış dosya sistemleri, hassas bölümler ve cihaz kimliği içerebilen devir görselleri yalnız yereldedir. Araç kurulumları/indirmeleri de yeniden üretilebilir yerel bağımlılıklardır. Bu nedenle bazı analiz belgelerinin yerel kaynak bağlantıları GitHub klonunda bulunmaz. Bunlar silinmedi veya değişmedi.

Kullanıcının tercihi: bundan sonraki yetkili proje çalışmaları tamamlandıkça hassas veri kontrolü, commit ve push ile senkron ilerle. Gözetimsiz otomatik görev kurulmadı.
